# Selected team logos

These marks identify prior work; ownership remains with their respective brands.
The UI uses CSS masks so every mark inherits the theme's muted foreground.

Original SVG sources:
- Lyft: https://cdn.lyft.com/static/lyftcomfe/lyft-logo.svg
- Ford: Simple Icons v13, https://cdn.jsdelivr.net/npm/simple-icons@v13/icons/ford.svg (CC0 collection)
- Afresh: https://logos-download.com/brands/afresh (2022 SVG)
- HomeVision: https://www.homevision.co (Webflow header asset)
- Lettuce: https://lettuce.co/hubfs/Logo%20files/Logo@2x.svg
- Bluecadet: https://www.bluecadet.com (inline header SVG)
- Swift Industries: https://builtbyswift.com (Shopify header SVG)
- PleasrDAO: https://pleasr.org/strapi/uploads/pleasrdao_logo_ed838f6f00.svg (monochrome cutouts preserved)

User-provided SVG originals:
- Continuum: `continuum.svg`, supplied by Alex Bloom.
- Cinereach: `cinereach.svg`, supplied by Alex Bloom.

Traced vector sources, used because original vector files were unavailable:
- Tribeca Film Institute: the original mark on https://www.documentary.org/nonfiction-core-application-project (Tribeca_Logo.jpg); this is the Institute, not the Festival.

Traces are monochrome approximations of source artwork, not new brand designs.
